FITNESS TRACKER FRONTEND - USER + HIDDEN ADMIN PANEL

1) Install Node.js LTS first.
2) Open CMD inside this project folder.
3) Run:

npm install
npm run dev

Public website:
http://localhost:5173/

User flow:
- Navbar only has Login and Sign Up buttons.
- User dashboard is protected.
- Login or Sign Up first, then user dashboard opens.
- User logout button is available in the dashboard topbar.
